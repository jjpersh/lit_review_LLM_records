## 2. Eligibility
Yes, this is a core paper. In every tested setup, an on-premise open-weight LLM (Qwen3-14B, and in one comparison Qwen2.5-7B/14B and Llama-3.1-8B) proposes PI controller gains. Each proposal is simulated in closed loop, and the resulting cost is fed back to the LLM. In a second architecture, the LLM proposes the one design parameter (τ) of a direct data-driven tuning method. The plants are process systems: the PC-Gym CSTR, the PC-Gym quadruple-tank (a standard benchmark) and a synthetic 3×3 linear coupled plant. Everything runs in simulation, offline, at design time.

## 3. What was built, in plain words
**Plants.** All plants are simulations from PC-Gym, an open process-control simulator suite, plus one custom plant:
- a single-loop CSTR (concentration Ca controlled with coolant temperature);
- a nonlinear 2×2 quadruple-tank (two pumps v1, v2 control the two lower-tank levels h1, h2), with strong cross-coupling (RGA λ11 = −0.06) and conflicting set-point changes;
- a synthetic linear 3×3 cyclic-coupled plant.

**Controller.** The actuator is moved by an ordinary position-form PI controller in each loop, with cross pairing (v1→h2, v2→h1), clamping anti-windup and pumps saturated at 0.1–10 V. Actuation is continuous.

**Where the LLM sits.** The LLM is a design-time tuner and is never in the real-time loop.
- **Scaffolded tuner.** The prompt contains a prose summary of the measured step-test coupling, the cost J = IAE + 0.75·TV(u), a hint that "balanced tuning fails; the best controller emphasizes one loop", and a required JSON output with a worked example ({"Kp1":200,…,"Kp2":8,…}).
- **Iteration.** Each round, the LLM returns four gains as JSON. These are simulated over a 120-step, 400 s episode, and J with its IAE/TV breakdown goes back into the prompt. This repeats for 18 rounds at temperature 0.9.
- **Output handling.** Gains are clipped to [−50, 1500]. Unparseable output is skipped and retried.
- **Hybrid.** The best gains from the LLM run are used as the starting point for Nelder–Mead (a local simplex optimizer), which refines all four gains.
- **"Naive LLM" baseline.** The same loop, but with no process knowledge in the prompt.
- **LLM-guided VRFT.** VRFT (Virtual Reference Feedback Tuning) fits PI gains by least squares from a single open-loop experiment, given a reference-model time constant τ. In this variant, the LLM receives per-level 63.2 % rise times and proposes one τ, with a 2500-token generation budget. VRFT then fits the gains and Nelder–Mead refines them.

**Models.** No fine-tuning was done. Models were served locally with HuggingFace transformers in bf16 on one RTX 6000 Ada.

## 4. Each tested setup
**Setup A: CSTR single loop, scaffolded LLM tuner (p.12).**
- Same closed-loop feedback and number of rounds as the classical comparator.
- Comparator: relay-feedback Ziegler–Nichols (a tuned classical auto-tuner), plus a multi-start numerical optimum.
- Metric: IAE.
- Multiple seeds ("never better across seeds"), but no spread is reported.

**Setup B: Quadruple-tank, scaffolded LLM gain proposals plus Nelder–Mead hybrid (p.5–6, p.12–24).**
- 10 decoding seeds for both the scaffolded LLM and the hybrid.
- Comparators:
  - no control;
  - decentralized relay-ZN;
  - naive LLM;
  - Nelder–Mead from 10 balanced starts;
  - Latin-hypercube multi-start Nelder–Mead;
  - differential evolution (DE, 3 runs; budget sweep);
  - Bayesian optimization (10 runs at 40 evaluations, 5 runs at 150 and 250);
  - inverse-gain heuristic;
  - static decoupler;
  - enumerated dominance grid;
  - VRFT plus refinement (10 open-loop experiments).
- Metrics: J, IAE, TV, success rate (J < 20), and evaluation count.
- What was varied:
  - four LLMs (single runs each);
  - prompt ablations (hint removed; format example neutralized, 5 seeds; raw gain matrix only);
  - penalty weight λ from 0.2 to 1.0 (5 runs of the LLM-style prior per λ);
  - multiplicative noise on the LLM prior (σ = 10/25/50 %, 10 runs each).
- No disturbances, model mismatch or process noise (the simulator is deterministic).

**Setup C: 3×3 cyclic synthetic plant, scaffolded LLM plus hybrid (p.19–20).**
- 10 seeds.
- Comparators: DE (10 runs per budget, 360–4680 evaluations), naive Nelder–Mead (20 starts), and the inverse-gain heuristic (9/15).
- VRFT was not run on this plant.
- Metrics: J, success rate (J < 2.42), and evaluations.

**Setup D: Quadruple-tank, LLM proposes the VRFT τ from rise-time summaries (p.21–22).**
- 10 open-loop experiments (seeds).
- Comparators: VRFT with an 11-point τ grid scan, and a deterministic median-rise-time rule.
- Metrics: J after refinement, commit rate, and paired Wilcoxon tests.

## 5. Results
- **CSTR (p.12), metric IAE, lower is better:** "Relay-feedback Ziegler–Nichols reaches IAE 0.106 … the scaffolded LLM … settles at IAE 0.162." The LLM is about 50 % worse than relay-ZN, which is itself near the 0.102 optimum. **The LLM loses to the non-LLM method.**
- **Quadruple-tank naive methods (p.6, p.12), J = IAE + 0.75·TV, lower is better:** "decentralized relay tuning yields 𝐽 28.6 … worse than open loop (𝐽 22.7)". The naive LLM scores J 29.7.
- **Local optimizer (p.16):** "Nelder–Mead fails to reach the optimum region in all 10 runs (mean 𝐽 28.0, range 23.4–30.2". The denominator is 10 hand-picked balanced starts.
- **Scaffolded LLM (p.16):** "reaches 𝐽 16.9 ± 0.2 over ten decoding seeds". All 10/10 runs are in the J < 20 region (Wilson interval 72–100 %).
- **Hybrid (p.16):** "local refinement reaches 𝐽 12.0 ± 0.16 (IAE 9.1, TV 3.9) in 10/10 cases".
- **Against black-box search (p.19):** the LLM gives a usable controller in 18 evaluations, while "DE returns 𝐽 25.6 and BO returns 𝐽 23.9" at about 40 evaluations. **The LLM beats DE and BO on sample efficiency at small budgets.** The full hybrid (about 420 evaluations) is comparable to DE at about 360, with no advantage.
- **VRFT (p.20–21):** "refinement reaches 𝐽 < 13 in 10/10 cases, mean 𝐽 = 11.12 ± 0.05". VRFT has lower cost (about 270 vs about 420 evaluations) and a better basin. **A non-LLM method beats the LLM hybrid on both quality and spread.**
- **Prompt ablation (p.23):**
  - With the format example neutralized: "mean 𝐽 = 13.86 ± 1.69". None of 5 seeds reached the 20–29:1 asymmetric ratio, so the reliability claim is withdrawn.
  - With only the raw gain matrix, J ranged from 18.6 to 27.1.
- **Across models (p.23), single runs:** Qwen2.5-7B J 13.6, Qwen2.5-14B 15.4, Llama-3.1-8B 14.3, against Qwen3-14B 16.9.
- **λ sweep (p.24):** the LLM-style prior reached the reference region in 5/5 runs at every λ; naive starts reached it in at most 2/10.
- **Noisy prior (p.25):** "reaches the optimum region in 9/10, 7/10, and 7/10" at σ = 10/25/50 %.
- **3×3 plant (p.19–20):**
  - Scaffolded LLM: J = 4.61 ± 0.98.
  - Hybrid: "𝐽=2.17 ± 0.11 … in 9/10 runs below the fixed 𝐽 < 2.42 success threshold". Mean cost is 294 evaluations, against about 2400 for DE, roughly 8× fewer. **The LLM beats DE on sample efficiency.**
- **LLM-chosen τ (p.21):** "It committed to an answer in 8/10 seeds". The 8 successes reached "mean 𝐽 = 11.19 ± 0.17". The median rule "succeeded on 10/10 seeds" at J 11.17 ± 0.15. Paired p = 0.69 between the median rule and the LLM. **The LLM does not beat the simple rule.**

## 7. Terms to define
- **RGA (relative gain array):** an interaction measure built from the steady-state gain matrix. A diagonal element far from 1, or negative, means decentralized pairing is problematic.
- **J = IAE + λ·TV(u):** tracking error plus a weighted total variation of the pump signals, with λ = 0.75. Lower is better.
- **TV(u):** the summed absolute change of the control signals, scaled by actuator span. It is a proxy for control effort and actuator wear.
- **Scaffolded LLM:** an LLM whose prompt contains a coupling summary, a structural hint and an output format, iterated with cost feedback.
- **Hybrid:** LLM-proposed gains used as the starting point for Nelder–Mead local refinement.
- **Naive LLM:** the same iterative loop without process knowledge in the prompt.
- **VRFT (Virtual Reference Feedback Tuning):** fits controller gains by least squares from one open-loop data set so the loop matches a reference model.
- **τ:** the time constant of VRFT's first-order reference model.
- **DE / BO:** differential evolution and Bayesian optimization, both black-box global optimizers.
- **Reliable / success rate:** the fraction of runs that land in the good-cost region (J < 20, or J < 13 for VRFT comparisons; J < 2.42 on the 3×3 plant).
- **Structural prior:** which loop dominates and the rough gain ratio, which the optimizer then refines.
