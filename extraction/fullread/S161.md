## 2. Why it is context
The paper is a user study (N = 24) of fault troubleshooting support for a Bambu Lab P1P desktop 3D printer. People diagnose paper-based fault cases with one of three aids: a knowledge-graph chatbot, ChatGPT (GPT-3.5, free tier, no system prompt) or the online documentation (pp. 8–9). No control layer is involved. No LLM reads plant signals, proposes setpoints or tuning, or touches the machine. The outcomes are diagnosis accuracy on a rubric, time to answer and self-reported trust (p. 10). The knowledge-graph agent itself retrieves deterministically by embedding similarity and graph traversal; an LLM helps only with offline triple extraction (pp. 6–7). This is maintenance-diagnosis advice to a person, not control, so it does not meet the core screen.

## 3. Background use
- **Over-trust in fluent LLM advice (cite in 4.1 operator interface or 5.2 safeguards as background).** Participants trusted plain ChatGPT about as much as the grounded knowledge-graph tool (5.1 vs 5.4 of 7, p = .29). Its diagnostic accuracy was 29 points lower (0.52 vs 0.81 on a 0–1 rubric), giving an over-trust index of +0.41 against +0.06 (pp. 11–12). This supports the argument that a human reading LLM advice is a weak safeguard. It is not evidence about control performance.
- **A metric and design principles.** The Operator Trust Calibration Index (OTCI = (T−1)/6 − A, where T is trust and A is accuracy; positive means over-trust; p. 10) can be cited as one way to measure operator reliance. The paper also gives four principles: ground advice in verifiable knowledge, show provenance and uncertainty, separate fluency from authority, and build in escalation (pp. 13–14).
- **Infrastructure pattern.** Shows a human-in-the-loop build of a fault knowledge graph: LLM-assisted triple extraction, expert review below a confidence threshold τ = 0.75, 177 nodes and 221 edges. Each corrective action carries provenance metadata (pp. 5–7). It is a possible grounding layer for LLM operator assistants.

Caveats for any citation: the participants were students and lay adults, the machine is a consumer-grade printer, the LLM arm was GPT-3.5 without retrieval or domain prompting, and trust was self-reported (p. 13).
